# 게임 소개 페이지 가독성 개선

## 목표
- 기존 로고, 히어로, 맵, 캐릭터, 장애물, 아이템 이미지를 수정하지 않는다.
- 웹캠으로 몸을 움직여 노를 젓는 4인 2대2 게임이라는 점을 첫 소개에서 설명한다.
- 소개, 맵과 전용 장애물, 공통 아이템, 캐릭터, 다운로드 순서로 정보의 위계를 만든다.
- 크림·노랑·갈색으로 홈과 로그인·회원가입 화면의 색감을 통일한다.
- 설명은 문장 단위로 줄바꿈하며 아이템은 이미지 아래 이름·설명을 가운데 정렬한다.
- 소개 영역의 제목은 28–40px, 소제목은 20–24px, 본문은 16px, 보조 정보는 14px로 통일한다.

## 변경 범위
- HomePage.tsx의 소개 이후 구조, 로그인·회원가입의 공통 레이아웃과 해당 화면에 한정한 CSS.
- 맵 선택 버튼을 유지하고 선택된 맵의 장애물을 같은 패널에 표시한다. 공통 아이템은 별도 영역으로 분리한다.
- 미확정 영상은 로컬에만 보관한다. 개발 서버에서만 직접 경로로 불러와 표시하며 Git 추적과 배포 빌드에서는 제외한다.
- 로컬 영상 영역은 기존의 ‘직접 보는 노디세이’ 문구, 제목·설명, 재생 프레임, 하단 캡션을 유지하며 노란색 테마로 표현한다.
- 장애물 제목은 선택한 맵에 맞춰 강에서/사막에서 만나는 장애물로 표시하며 전용 배지는 사용하지 않는다.
- 캐릭터는 투명 원본 이미지와 색감 있는 배경, 바닥 그림자, 이름표로 구성하며 원본을 자르지 않는다.
- 플레이 안내는 다운로드 영역 아래의 간결한 정보표로 합친다.
- 기존 히어로, 인증, 게임 실행, 다운로드 API 동작은 보존한다.

## 검증 기준
- lint와 TypeScript를 포함한 프로덕션 빌드 통과.
- 데스크톱과 모바일에서 수평 넘침, 글자 잘림, 이미지 잘림이 없다.
- 맵 전환 시 이름, 이미지, 장애물이 함께 변경되고 공통 아이템은 그대로 유지된다.
- 빌드 결과에 MP4가 없고 원본 로컬 영상은 그대로 존재한다.
- 로컬 영상이 있으면 개발 화면에서 재생 가능하며 파일이 없는 다른 환경에서는 영상 영역을 숨긴다.
- 로컬 백엔드 연결은 실행 상태뿐 아니라 포트와 허용 웹 주소를 함께 확인한다. 메일 테스트 환경은 웹 5175 → API 8082이다.
- 로그인·회원가입의 입력, 비밀번호 보기, 유효성 안내, 이메일 인증, 약관과 이동 링크를 유지한다.
- 원본 테마 이미지의 Git 변경이 없다.

## 저장소 반영
- 기존 작성자 이연호의 Git 설정을 사용하고 관련 없는 변경은 포함하지 않는다.
- 커밋 메시지와 작성자 부가 문구에 생성 도구 이름을 추가하지 않는다.
- 이전에 푸시한 기록은 임의로 재작성하지 않는다. 이력에 남은 영상은 별도 정리 대상으로 안내한다.
