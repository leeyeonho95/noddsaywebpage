# 게임 소개 페이지 가독성 개선

## 목표
- 기존 로고, 히어로, 맵, 캐릭터, 장애물, 아이템 이미지를 수정하지 않는다.
- 웹캠으로 몸을 움직여 노를 젓는 4인 2대2 게임이라는 점을 첫 소개에서 설명한다.
- 소개, 영상, 맵과 전용 장애물, 공통 아이템, 캐릭터, 다운로드 순서로 정보의 위계를 만든다.
- 소개 영역의 제목은 28–40px, 소제목은 20–24px, 본문은 16px, 보조 정보는 14px로 통일한다.

## 변경 범위
- HomePage.tsx의 소개 이후 구조와 해당 페이지에 한정한 CSS.
- 맵 선택 버튼을 유지하고 선택된 맵의 장애물을 같은 패널에 표시한다. 공통 아이템은 별도 영역으로 분리한다.
- 영상은 소개와 맵 사이에 독립된 배경과 여백을 가진 영역으로 배치한다. 영상이 없는 경우에는 표시하지 않는다.
- 캐릭터는 투명 원본 이미지와 색감 있는 배경, 바닥 그림자, 이름표로 구성하며 원본을 자르지 않는다.
- 플레이 안내는 다운로드 영역 아래의 간결한 정보표로 합친다.
- 기존 히어로, 인증, 게임 실행, 다운로드 API 동작은 보존한다.

## 검증 기준
- lint와 TypeScript를 포함한 프로덕션 빌드 통과.
- 데스크톱과 모바일에서 수평 넘침, 글자 잘림, 이미지 잘림이 없다.
- 맵 전환 시 이름, 이미지, 장애물이 함께 변경되고 공통 아이템은 그대로 유지된다.
- 영상의 재생 컨트롤, 키보드 조작과 모션 감소 설정을 유지한다.
- 원본 테마 이미지의 Git 변경이 없다.

## 저장소 반영
- 기존 작성자 이연호의 Git 설정을 사용하고 관련 없는 변경은 포함하지 않는다.
- 커밋 메시지와 작성자 부가 문구에 생성 도구 이름을 추가하지 않는다.
