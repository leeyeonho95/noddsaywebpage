# 인식 문제 장면 (S15P31A206-297)

개발자 대시보드에서 경기 카메라 로그를 열어 인식이 잘못된 것으로 보이는 장면을 관절 뼈대로 다시 본다. 영상은 없고 로그에 남은 관절 좌표(J 줄)와 Unity가 적은 판정(F · REQ · GES · CANCEL · TEAM · NEAR, S15P31A206-295부터 ITEM · PROT · PNEAR)만 쓴다. 로그 형식은 게임 저장소 `docs/api/camera-logs.md`.

## 화면

- 개발자 메뉴 **인식 문제 장면** → `/dev-dashboard?tab=camera-replay`. 로그 파일을 끌어다 놓거나 눌러서 연다(gzip이면 브라우저에서 푼다).
- 경기 상세(카메라 요약이 있는 경기)의 **인식 문제 장면 보기** → `?tab=camera-replay&userId=…&eventId=…`. 서버 원본 로그 API(`GET /api/v1/web/developer/games/{userId}/{eventId}/camera-log`, 백엔드 S15P31A206-296)로 받아 바로 연다. 응답은 저장된 gzip 그대로(Content-Encoding 없음)라 화면이 앞 2바이트를 보고 푼다.
  - 버튼: 상세의 `cameraLogAvailable`이 true면 버튼과 원본 보관 기한(`rawExpiresAt`), false면 버튼 대신 까닭(보관 기간 지남 / 요약만 올라옴). 두 필드가 없는 이전 서버는 카메라 요약만 보고 버튼을 보인다(`src/lib/cameraLogStatus.ts`).
  - 받기 실패: 404(요약 · 파일 없음, API 이전 서버) · 410(원본이 안 올라옴 · 보관 기간 지남) · 503(서버 저장소 읽기 실패)마다 안내를 보이고 파일 열기로 둔다. `cameraLogAvailable`은 DB 기준 힌트라 버튼이 보여도 404 · 410이 날 수 있다.
- 왼쪽 목록에서 장면을 누르면 앞 3초~뒤 2초를 되풀이 재생한다. 0.25/0.5/1배속, 한 장면씩, 경기 전체, 좌우 뒤집기(기본은 게임 화면처럼 1P가 왼쪽), **영상 저장**(지금 구간을 webm으로).
- 캔버스: 자리 색 1P 파랑 · 2P 주황 · 3P 초록 · 4P 노랑, 판정에서 빠진 자리는 점선 회색. 이름표에 놓침 · 뒷사람 처리 · 켜진 동작 · 노 젓기 · 뭉침 · 보호 중. 위에 걸린 요청과 남은 시간, 방금 나간 팀 동작, 오른쪽 위에 팀 아이템(ITEM 줄이 있는 로그).
- 시간 막대: 요청(초록 성공 · 빨강 시간 초과 · 회색 취소), 팀 동작(파란 세로선), 숙이기 보호(보라 = 안 풀림, 회색 = 정상).

## 문제 장면 고르는 기준

판정이 아니라 '볼 만한 장면'을 고르는 기준이다(`src/lib/cameraReplay.ts`의 `T`).

| 종류 | 기준 |
| --- | --- |
| 요청 실패 | 성공 없이 창이 끝남(창 끝 0.25초 안에 거둔 것도 — 인식률 리포트와 같음). 자리마다 판정 제외 · 뭉침 · 그 동작이 켜졌는지, NEAR의 가장 가까웠던 조건, 두 사람 동작은 PNEAR의 사람별 자기 몫 |
| 팀 동작 혼자 끝남 | 독수리 · 탈출 X가 한 사람만 켜지고 4초 안에 팀 동작이 안 나감(요청 답 구간 제외). 짝의 판정 제외 · 뭉침 · 숙이기 보호, 독수리는 그때 팀 아이템 |
| 인식 안 된 동작 의심 | 플레이어로 잡혔고 켜진 동작이 없는데 두 손목이 어깨선 아래 어깨너비 0.5보다 위인 채 0.6초 넘게(노도 안 젓고 쉬지도 않는 자세). 두 손 벌림 = 독수리 비슷(ITEM 줄이 있으면 아이템 없는 팀은 뺌), 엇갈림 · 모음 = X 비슷 |
| 판정에서 빠짐 | 잡혔는데 뒷사람 처리 · 놓침이 1.5초 넘게 |
| 숙이기 보호 안 풀림 | PROT 줄에서 보호가 6초 시간 끝 · 연속 실패 · 로그 끝으로 끝남. 해제 검사에서 걸린 조건별 횟수. 겹치는 뼈대 뭉침은 이 장면으로 합침 |
| 뼈대 뭉침 | 코 · 어깨 · 엉덩이 · 무릎의 세로 범위가 화면 높이의 0.15 미만으로 2.5초 넘게 |

## 로그 받기(서버 원본 API 전)

- 운영 경기: 게임 저장소 `python scripts/camera-recognition-report.py --since 날짜`(읽기 전용) → `Logs/camera-report/prod/경기ID.csv.gz`
- 개발 PC: 게임 저장소 `Logs/camera/camera-*.csv`
